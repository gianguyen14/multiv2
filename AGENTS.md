# Engineering Rules

- Do not change architecture without approval.
- Do not add dependencies without approval.
- One module = one responsibility.
- Do not duplicate business logic.
- Preserve existing API contracts.
- Every new behavior requires tests.
- No hard-coded competition scoring rules without official specification.
- Do not modify unrelated modules.
- Do not refactor working code during feature work.
- Run tests before reporting completion.
- Report all changed files.
- Report benchmark impact for retrieval changes.
- Experimental model changes must stay isolated behind configuration flags.
